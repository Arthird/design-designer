## Freshness process

1. Re-open the pinned 2025.10 format and Color module before changing normative validation rules.
2. Compare type definitions, reference semantics, and group behavior with the project's validator/generator.
3. Distinguish a new format revision from an implementation preference in Style Dictionary.
4. Update pinned reference links, supported type lists, and validation notes together.
5. Manually re-check `token-writer` against malformed, unresolved, cyclic, and unsupported-value examples.

Do not substitute a blog post or tool documentation for an applicable DTCG normative requirement.

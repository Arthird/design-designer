| Field | Value |
|---|---|
| Primary source | WHATWG HTML Living Standard |
| Official URL | https://html.spec.whatwg.org/ |
| Version/revision | Living Standard |
| Supporting sources | MDN HTML and CSS documentation; W3C WCAG 2.2 / WAI-ARIA APG for accessibility-specific concerns |
| Last checked | 2026-11-26 |
| Next review | Before any release that changes HTML/CSS implementation rules |

## Freshness process

1. Re-check the relevant HTML standard section before making a normative semantics claim.
2. Use MDN for current practical examples, browser-facing syntax, and CSS support notes.
3. Re-check CSS custom-property and pseudo-class behavior when the chosen pattern is version-sensitive.
4. Update the HTML/CSS rule and this metadata when the applicable standard or practical browser behavior changes.
5. Manually inspect the affected static HTML/CSS example and its rendered states; do not infer runtime interaction from source alone.

MDN and WHATWG can differ in purpose. Prefer the HTML standard for normative behavior and MDN for current implementation-oriented explanation.

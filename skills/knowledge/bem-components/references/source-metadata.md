## Freshness process

1. Re-read the BEM methodology, naming, and CSS pages before changing core selector or naming rules.
2. Confirm that the project still wants BEM for its component prototypes; if not, document a deliberate alternative.
3. Update examples and selector checks together when terminology or composition guidance changes.
4. Manually inspect HTML/CSS pairs for semantic correctness separately from naming.

BEM does not replace project accessibility goals, semantic HTML, or token governance.

# Knowledge Skills

These installable knowledge skills provide domain rules and decision criteria:

- `ux-design-intelligence`
- `design-tokens-standard`
- `web-accessibility`
- `web-ui-foundations`
- `bem-components`
- `apple-platform-guidance`
- `material-platform-guidance`

Install all knowledge skills as a group:

```bash
npx skills@latest add Arthird/design-designer --skill ux-design-intelligence --skill design-tokens-standard --skill web-accessibility --skill web-ui-foundations --skill bem-components --skill apple-platform-guidance --skill material-platform-guidance
```

Knowledge skills do not execute project workflows by themselves.

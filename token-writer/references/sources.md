# Token Writer References

- Token structure, references, types, and metadata: [Design Tokens Format Module 2025.10](https://www.designtokens.org/TR/2025.10/format/). This is the applicable Design Tokens Community Group specification, not a W3C Standard.
- Deterministic token transforms and platform output: [Style Dictionary](https://www.styledictionary.org/) and [transforms](https://www.styledictionary.org/reference/hooks/transforms/).
- CSS custom properties: [MDN CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties).
- Web accessibility implications: [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
- Platform guidance when relevant: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) and [Material Design 3](https://m3.material.io/).

Format validity does not establish visual contrast, platform suitability, or complete accessibility.

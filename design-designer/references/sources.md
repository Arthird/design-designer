# Primary References

Consult a source only when its subject is relevant. Prefer official specifications over summaries.

- Skill structure and progressive disclosure: [OpenAI Build Skills](https://learn.chatgpt.com/docs/build-skills), [OpenAI Skill Creator](https://github.com/openai/skills/tree/main/skills/.system/skill-creator), [Testing Agent Skills](https://developers.openai.com/blog/eval-skills).
- Token format: [Design Tokens Format Module 2025.10](https://www.designtokens.org/TR/2025.10/format/). This is the applicable Design Tokens Community Group specification, not a W3C Standard.
- Deterministic token transforms: [Style Dictionary](https://www.styledictionary.org/) and [transforms](https://www.styledictionary.org/reference/hooks/transforms/).
- Web accessibility: [WCAG 2.2](https://www.w3.org/TR/WCAG22/), [Understanding WCAG](https://www.w3.org/WAI/WCAG22/Understanding/), [WAI tutorials](https://www.w3.org/WAI/tutorials/), and [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/).
- Web platform syntax: [WHATWG HTML](https://html.spec.whatwg.org/), [MDN HTML](https://developer.mozilla.org/en-US/docs/Web/HTML), [MDN CSS reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference), [CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties), and [CSS pseudo-classes](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-classes).
- CSS architecture: [BEM methodology](https://en.bem.info/methodology/), [naming](https://en.bem.info/methodology/naming-convention/), and [BEM CSS](https://en.bem.info/methodology/css/).
- Platform conventions: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) and [Material Design 3](https://m3.material.io/).
- Optional design intelligence: [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).

Do not describe the Design Tokens specification as W3C normative. Do not claim automated checks satisfy WCAG globally; they cover only the assertions implemented for the project.
